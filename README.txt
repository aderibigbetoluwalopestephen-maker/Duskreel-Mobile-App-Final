DUSKREEL MOBILE APP

This package is a mobile/PWA build based on the existing Duskreel editor.

Included:
- Existing editor functionality
- Duskreel gold camera logo
- Mobile responsive layout enhancements
- PWA manifest and install support
- Offline app shell
- Touch-friendly controls

DEPLOYMENT
1. Upload all files in this folder to the same web directory.
2. Serve the site over HTTPS.
3. Open it on Android Chrome or iPhone Safari.
4. Use Add to Home Screen / Install App.

The image editor still runs in the browser; no server is required for the basic editing UI.
